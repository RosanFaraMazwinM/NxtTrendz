# NxtTrendz #
Live Website : https://nxttrndzweb.ccbp.tech/login

A React-based e-commerce shopping application that allows users to browse products, manage their shopping cart, and experience a simple online shopping workflow.

## 🚀 Features

- Browse and view products.
- Add products to the shopping cart.
- Increase or decrease product quantities.
- Remove products from the cart.
- View the total cart value.
- Responsive user interface.
- Manage cart items dynamically using React.

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- React Router
- REST API

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/RosanFaraMazwinM/NxtTrendz.git
```

2. Navigate to the project folder:

```bash
cd NxtTrendz
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm start
```

5. Open your browser and visit:

```text
http://localhost:3000
```
